RAPORT WERYFIKACJI ONLINE — NAPRAWA PC HARDWARE TEST PRO
==========================================================

Ten raport jest celowo wersjo-neutralny. Dokładny numer wydania, rozmiar i SHA-256 instalatora należy odczytać z manifestu stable:
https://github.com/naprawapclaptop1-dev/serwis-ai-chat/blob/main/updates/hardware-test-pro/latest.json

Windows CI dla każdego wydania uruchamia poniższe kontrole. Status konkretnego przebiegu jest dostępny na stronie workflow:
https://github.com/naprawapclaptop1-dev/serwis-ai-chat/actions/workflows/hardware-test-pro-build.yml

ZAKRES KONTROLI CI
[ ] Windows x64 / Python 3.12 / .NET 10.
[ ] Odtworzenie źródła, zasobów graficznych i Sensor Bridge.
[ ] Kontrola składni Pythona i wbudowane testy core/deep/updater/launcher/antivirus/themes/service-center/update-flow.
[ ] Testy sensorów: pełna tabela, per-core CPU, RAM/swap, dyski/NIC/woluminy, zachowanie N/D i scalanie poprawnych odczytów.
[ ] Speed Test: walidacja HTTP i przesłanych bajtów, mediana bazowa, profile QUICK/STANDARD/MAX/TURBO oraz osobny wynik równoległego transferu.
[ ] GPU: 110 ID scen, 31 trybów geometrii, unikalne sygnatury scen, renderer FurMark-style i synchronizowany pomiar FPS.
[ ] 15 grup i 110 odrębnych testów; 40 odczytowych sond integracyjnych System Repair PRO / Serwis Ultimate.
[ ] Serwis Ultimate: menedżer procesów z ochroną procesów krytycznych, odczytowa diagnostyka gier i menedżer lokalnych raportów.
[ ] System Repair PRO: centrum napraw Windows, 14 profili problemów, baza wiedzy i raporty.
[ ] PyInstaller EXE, kompilacja/weryfikacja Inno Setup, publikacja Setup.exe i ALL-IN-ONE ZIP oraz zgodność manifestu i SHA-256.

WERYFIKACJE POZA CI
[ ] Uruchomienie GUI na fizycznym komputerze użytkownika.
[ ] Potwierdzenie temperatur, mocy, zegarów i obrotów wentylatorów na konkretnych sterownikach.
[ ] Fizyczne testy matrycy, baterii, klawiatury, audio, USB i pozostałych peryferiów.
[ ] Instalacja/aktualizacja nad istniejącą instalacją na komputerze użytkownika.
[ ] Porównanie plik-po-pliku wszystkich ekranów, metod, handlerów i raportów z archiwami źródłowymi System Repair PRO 5.6.25 oraz Serwis Ultimate 1.15.3.

OGRANICZENIA I UCZCIWY STATUS
- CI potwierdza budowanie i samodzielne testy kodu, ale nie zastępuje pomiarów na fizycznym sprzęcie.
- N/D oznacza brak danych udostępnionych przez sterownik lub system; nie wolno zastępować go wymyśloną temperaturą ani statusem PASS.
- Test pamięci aplikacyjnej nie gwarantuje sprawdzenia każdej fizycznej komórki RAM.
- Wynik Speed Testu zależy od połączenia, serwera i warunków sieci.
- 40 sond to istniejąca integracja diagnostyczna, a nie dowód pełnej zgodności 1:1 z dwoma oryginalnymi projektami.
- Pełna parytetowość wszystkich funkcji źródłowych pozostaje niepotwierdzona do czasu porównania obu archiwów i testów fizycznych.

ZASADA PUBLIKACJI
Nie uznawać wydania za gotowe, jeżeli najnowszy Windows CI nie zakończy się sukcesem, nie ma obu plików wydania lub manifest nie zgadza się z SHA-256 instalatora.
