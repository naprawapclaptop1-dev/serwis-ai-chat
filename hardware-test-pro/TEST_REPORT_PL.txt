OGRANICZENIA — NIE NALEŻY ICH UKRYWAĆ
- Sukces GitHub Actions potwierdza kroki CI/builda. Nie jest dowodem, że wszystkie fizyczne czujniki działają na każdym komputerze.
- Temperatury, moc, zegary, wentylatory, VRAM i wykorzystanie GPU zależą od sterowników, Sensor Bridge i sprzętu; brak odczytu musi pozostać N/D.

- Testy klawiatury, touchpada, audio, kamery, matrycy i baterii mogą wymagać fizycznego urządzenia albo interakcji operatora.
- Speed Test wykorzystuje rzeczywisty transfer danych i może być ograniczony przez sieć lub endpointy.
